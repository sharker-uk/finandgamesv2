# Fin & Games Marketing Engine

This directory contains the specification and future implementation of the Fin & Games automated marketing engine.

Start with [SPECIFICATION.md](./SPECIFICATION.md).

The engine is designed to turn Fin & Games development and publishing activity into platform-specific marketing campaigns while keeping human approval in control of public publishing.

Initial target platforms:
- Bluesky
- X
- Discord
- Pinterest
- YouTube
- TikTok

The architecture is intentionally game-agnostic so future Fin & Games titles can use the same system.
