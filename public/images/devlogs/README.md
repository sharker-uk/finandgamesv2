# Game devlog images

Store public screenshots and artwork used by game development logs here, preferably grouped into a folder per article or milestone.

Example Markdown:

    ![Early terrain test](/images/devlogs/terrain-test/early-terrain.png)

    *The first pass at the terrain autotiling.*

Use .png for pixel art and interface captures; use .jpg for photographic or continuous-tone images. Include meaningful alt text and avoid committing oversized originals when a web-sized export is sufficient.
